# Aerospace-Avionics-Simulations
"A collection of aerospace hardware systems and flight computer logic built with Arduino."
Spacecraft Cabin Environmental Telemetry System (ECLSS)
This project is a simulation of an active environmental monitoring system for aerospace cabins, built using Arduino and Tinkercad. It utilizes a TMP36 sensor to continuously monitor ambient temperatures, mapping raw analog voltage data into Celsius. The flight computer logic features an automated safety protocol: if the cabin temperature exceeds a critical 30°C threshold, it instantly triggers an active Piezo audio alarm and a visual Red LED warning. This project demonstrates core avionics architecture, sensor data processing, and hardware-software integration.
